### Fandom Wiki Generator

- Một wiki static site mà tôi có thể thèm các nhân vật, sự kiện, để xây dựng các bộ truyện thông qua các File yaml config có lệnh Build ở local/thông qua CI/CD để tự động sinh HTML/CSS File là các page Wiki thông tin nhân vật/sự kiện tương ứng với các file config. Template có cấu trúc giống Wikipedia, lưu trữ và hệ thống liên kết các nhân vật và sự kiện trong nhiều bộ truyện/vũ trụ

- Có thể deploy thành web tĩnh trên GitHub Pages hoặc Vercel trở thành một wiki site, không cần tương tác CRUD, người dùng chỉ cần là admin thèm các file config yaml vào reo GitHub và chạy CI/CD để tự sinh page.
